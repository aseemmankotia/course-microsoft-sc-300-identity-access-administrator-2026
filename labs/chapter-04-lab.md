# Chapter 4 Lab: Conditional Access: Assignments, Conditions & Controls

**Estimated time:** 25 minutes

## Exercise

Build a Conditional Access policy requiring MFA for all users assigned Global Administrator when signing in from outside named trusted locations, deploy in report-only mode, then use the What If tool to validate before enforcing

## Key takeaway

Conditional Access grant controls are cumulative across all applicable policies, and report-only mode never enforces anything.
