# Chapter 3 Lab: Multi-Factor Authentication, Passwordless & Self-Service Password Reset

**Estimated time:** 20 minutes

## Exercise

Configure the Authentication methods policy to enable FIDO2 security keys and Temporary Access Pass while disabling SMS, then enable SSPR for a pilot group requiring two authentication methods for reset

## Key takeaway

The Authentication methods policy is the modern, unified place to control every method — treat legacy MFA settings as deprecated for exam purposes.
