# Chapter 10 Lab: Lifecycle Workflows & Application Access Governance

**Estimated time:** 20 minutes

## Exercise

Create a leaver lifecycle workflow that disables the user account, removes group memberships, and revokes sign-in sessions on the employee's last day, then configure user consent settings to route high-risk permission requests to an admin consent workflow

## Key takeaway

Lifecycle workflows automate identity lifecycle events, but blocking user consent without an admin consent workflow leaves no approval path at all.
